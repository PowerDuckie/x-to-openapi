# @powerduck/x-to-openapi
Production-oriented extensible `x -> OpenAPI 3.2` TypeScript framework. Current adapter: `curl`.

## Included
- CurlConverter -> HAR normalization
- Browser DevTools `Copy all as cURL` batch support
- JSON/XML/form-urlencoded/multipart/binary/text
- Multipart file schema inference
- Query/header/cookie/security inference
- Multi-request merging and path parameter inference
- OAS 3.2 `additionalOperations`
- OpenAPI 3.2 types and parser validation

## Run
npm i
npm run check
npm test
npm run demo
